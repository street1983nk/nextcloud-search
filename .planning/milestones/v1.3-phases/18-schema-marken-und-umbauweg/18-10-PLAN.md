## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Container -> Adminseite | Werte aus dem Container werden als Text in eine Nextcloud-Seite gerendert |
| Adminseite -> Admin | Ein Banner mit falschem Rat kostet den Nutzer echte Stunden |
| Statusroute -> Termwoerterbuch | Eine Messung, die je Abruf laeuft, ist eine Selbstlast |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-10-01 | Information Disclosure | `/status` und `/diagnose` | mitigate | Die neuen Werte sind Sprachcodes, Zahlen und Flags; kein Pfad, kein Dokumentname, kein Nutzertext, wie in den Modulkoepfen der beiden Routen festgehalten |
| T-18-10-02 | Elevation of Privilege | Neue Werte auf einer Route | accept | Keine neue Route, keine Aenderung an `appinfo/info.xml`; `/status` ist bereits ADMIN und liegt hinter der adminpflichtigen PHP-Route |
| T-18-10-03 | Denial of Service | Fuellstandsprobe bei jedem Abruf | mitigate | TTL-Cache nach dem Muster von `_DEGRADED`, unter demselben `_LOCK`, Schluessel `index_dir` |
| T-18-10-04 | Tampering | Cross-Site-Scripting im Banner | mitigate | Der Text liegt in einem eigenen `span` und wird ueber das vorhandene `text(...)`-Muster gesetzt, also ueber `textContent` und nie ueber `innerHTML`; die Fortschrittszahl ist eine Zahl aus dem Container und wird als solche geprueft |
| T-18-10-05 | Repudiation | Falscher Rat im Banner | mitigate | Eigener Bannertext ohne `occ findling:index --restart`; das alte Banner bleibt unveraendert daneben stehen |
| T-18-10-SC | Tampering | npm/pip/cargo installs | accept | Kein Paket; keine Bewegung an `composer.json` oder `pyproject.toml` |
</threat_model>
