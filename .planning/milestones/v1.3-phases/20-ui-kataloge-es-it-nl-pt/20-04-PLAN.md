## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Katalogwert zu vsprintf | Jeder spanische Wert wird in `L10NString::__toString` formatiert; ein nacktes Prozentzeichen ist dort eine Ausnahme und keine Zeichenkette |
| Katalogwert zu Browser | `OC.L10N.register` laedt die `.js`, die Werte landen ueber `textContent` in der Seite |
| Doku zu Gate | Ausnahmeliste und Pruefergebnisse stehen an zwei Orten und muessen dasselbe sagen |
