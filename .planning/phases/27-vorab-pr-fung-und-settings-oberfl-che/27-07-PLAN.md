## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> PHP-Routen | untrusted Werte und Aufrufer; Admin-Sitzung und requesttoken nötig |

| PHP -> appconfig | einzige Schreibstelle für Profil, Präzision, Bestätigung |
